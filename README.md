# Sistema Web para Petshop
## Fase 2

Projeto em desenvolvimento para a disciplina Fundamentos de Sistemas Web.

O projeto consiste na criação de um sistema web para petshop utilizando HTML, CSS/Bootstrap e JavaScript.

 ### Funcionalidades:
 - Exibição de informações sobre o petshop
 - Leitura por voz do conteúdo da página.
 - Exibição dos serviços ofertados, com descrição e valores.
 - Exibição dos produtos oferecidos, com descrição e valores. 
 - Navegação entre seções da página.
 - Formulários de cadastro de clientes e de animais de estimação.
 - Agendamento de serviços.

### Observações:
Os formulários de contato, cadastro de clientes, cadastro de pets e agendamentos são apenas ilustrativos e utilizam o recurso localStorage do próprio navegador, sem compartilhamento automático entre diferentes navegadores ou dispositivos.
